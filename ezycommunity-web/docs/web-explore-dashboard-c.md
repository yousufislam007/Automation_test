General UI facts used below
- Dialogs are `[role=dialog]`. Most close with Escape; the **Create Paywall dialog does NOT close on Escape** (use `Cancel`).
- Row menus are buttons with `aria-haspopup=menu`, items are `role=menuitem` (usually no accessible name on the trigger; use `tbody tr` + `button[aria-haspopup=menu]` last).
- Rows-per-page selects (`role=combobox`, `data-slot=select-trigger`, text "15") exist on Campaigns and Segments only; options 15 / 25 / 50 / 100 (not changed). Posts, Media storage, Meetings Past use Previous/Next (20 per page; Next then Previous returned 20 rows both ways). Previous/Next are disabled (single page) on Earnings, Billing history, Invitations, Blogs, Paywalls, Channels.

- Locators: `getByText(/^Awaiting approval/)` (button name includes the count), `getByRole('button',{name:'Confirm payment'})`.
- Not clicked: Confirm payment, Decline, Record payment, Copy reference, proof link.
