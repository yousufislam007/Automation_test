## Shared layout (all /dashboard/* pages)
- Page title format `<Page> | SQA Team` (exceptions below). Each page has H1, grey subtitle, a disabled `Analytics` button (top bar), icon buttons with aria-label `Open messages`, `Open notifications`, `Open profile menu`, `Expand sidebar`.
- Left admin nav (links by name): Dashboard, Website, Reports, Content, Members, Course tools, Gamification, Meetings, Paywalls, Paywall Groups, Earnings And Orders, Community App, Marketing, Automations, Roles & Permissions, Billing and Transactions, Settings, Developers. Top bar: Home /feeds, Courses, Events, Members, Leaderboard.
- Tables use `<table>` with `th`. Row action buttons are icon-only with NO accessible name (paywalls row = 4 unnamed buttons, earnings row = 1). Hard to locate by role; use `tbody tr` plus nth.
