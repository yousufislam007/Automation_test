### Community page (admin view)

- Header: cover with **Edit Cover Photo**, profile picture, name, short description, counters (Member, Channels, Posts).
- Tabs: the 13 from Tab Settings (URL `?status=myfeed`, `saved`, `hidden`, `leaderboard`, `meetings`, `members`, `photos`, `videos`, `audios`, **`fiels`** (sic), `events`, `courses`).
- Left: **Channels** with **Sort channels** and **+** (new channel). Right: channel description and the member list.
- **Post composer** ("Write something..."): text with `@everyone` / `@username` mentions; **6 colour backgrounds** (a coloured post is text only); **GIF** (online GIF search); **Photo** (Gallery, images); **Video** (Gallery: mp4, mkv, mov, or "Upload Video From URL"; each video has an "Add DRM" button; max 1 GB); **Audio** (Gallery: mp3, m4a, wav, ogg, oga, **"only mp3 and m4a are supported in the app"**, also "Click to start recording"; max 1 GB); **File** (Gallery File/Doc, max 100 MB); **Poll** (options, "+ Add option", settings "Allow people to choose multiple answers" and "Allow anyone to add options"); **Post anonymously**; **Schedule this post** (date and time, past days disabled, 24 h, time zone, default Asia/Dhaka).
- Post card: author, time, "Public", ⋮ menu (**Save post, Turn on notifications, View post, Copy post link, Hide, Edit Post, Pin Post, Delete Post**), **Like** (hover shows 6 reactions: Like, Love, Wow, Sad, Haha, Angry), Comments, Save post; comment box with emoji, image and GIF. A pinned post shows a pin icon and moves to the top.
- An anonymous post shows "Anonymous" with a placeholder picture (no badge).
- My Feed shows the admin's own posts **including the scheduled one**, labelled "SCHEDULED at ..."; the main Feed hides it.
- **New channel** (+): Channel name (required), Description, Post Permission (**Everyone can post / Only admin can post**), Pricing (**Free / Premium / Locked**, Premium needs a payment gateway), Strike Through Price (USD). Channel ⋮ menu: **Enrollment** (Manage Channel Enrollment: Add Member / Existing Member, Enroll now, Save), Edit, Delete. A Locked channel shows a "Lock" badge and **Add Custom Text** (rich text; afterwards "Edit Custom Text").
- **Meetings tab**: "Select a meeting" + **Add Meeting**. The list only offers the admin's own scheduled meetings (the event and lesson meetings are not offered; with none it says "No Data" and Add Meeting says "Please select a meeting"). The result is a meeting post with a countdown and **Join Meeting**; it shows only in the Meetings tab, not in the Feed.

### API calls seen (for automation and clean-up)

`POST /api/teacher/community/createNewCommunity`, `/create-enrollment`, `/communityTabSetting`, `/createFeed` (every post and the meeting post), `/toggle-pin-post`, `/createLike`, `/saveFeedforUser`, `/createNewSpaces` (channels are "spaces") with `/followUnfollowSpace`, `/createOrUpdateSpaceText/<spaceId>`; comments and replies use the student API `POST /api/student/comment/createComment`; gallery: `/api/teacher/gallery/createFolder`, `/uploadFile`, `/insertLink`; meeting: `/api/teacher/ezy-meeting/check-schedule-overlap`, `/api/teacher/ezy-meeting/instant/create` (201, also for a scheduled meeting). All answered 200 (the meeting create 201).

## Not done (and why)

- **Web**: no price or plan, no Premium channel (both need a payment gateway, a site setting); no "List on EzyCourse"
  (publishes outside the site); no instant meeting (it starts at once); no group chat (separate product); no `@everyone` or
  `@username` mention (sends notifications); no poll vote (kept for a later student test); no Hide post; the student was not
  enrolled in the locked channel; one community only (Private, Hidden and Restricted access, Member Only visibility,
  Draft status, enrollment limit and after-checkout page were only read, not tried); nothing edited or deleted.
- **App**: nothing posted, commented, reacted, saved, hidden, reported, voted or downloaded; no Message, Join Meeting,
  Registered, bell (notification) or "Mark all as read" taps; nothing typed. The WAV and the video were played once each
  to check playback, then stopped.
